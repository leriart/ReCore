// 03 WHY RECORE

THE CLIENT WITHOUT THE BROWSER

ReCore is a fork of Yapfast. It talks to Discord's API itself and draws its own window with iced, so the 720 MB Chromium that Discord's app carries is not here.

01

LIGHT, MEASURED

30 MB of RAM idle, 41 MB with pictures and GIFs in view, 44 MB in a call and 113 MB while sharing a 1080p screen. Servers, DMs, threads, forums, friends, voice, screen sharing and GIFs are exercised by the fake-Discord and UI tests; the method, raw conditions and numbers are published.

METHOD AND NUMBERS

02

RECORD'S LOOK

Signal orange, warm charcoal, paper-coloured type and Pixel Operator. ReCore and ReCore Paper are the fork's own themes; an accent picker retunes every signal shade.

03

CSS IN

Drop a Vencord or Vesktop .theme.css file in the themes folder. ReCore reads its palette, fonts, radius, background and options without a browser engine.

04

OPTIONS OUT

Each CSS theme's custom properties become switches, sliders, colour fields and picture pickers in Appearance, labelled from the theme's variable names, comments, @property rules and @var metadata. Recommended and changed filters, per-option resets, URL import and a disk cache make large themes practical. No CSS editing required.

// 04 CSS

THE INTERPRETER

A theme written for Discord's web window is not a theme a native window can paint one-to-one. ReCore reads the palette and the look, and matches the selectors that name Discord's regions — sidebar, chat, members, composer — onto its native window.

01

READ

Discord tokens and the theme's own variables, var(), color-mix(), light-dark(), hwb(), oklab() and oklch(), bare RGB triples from DiscordRecolor, local and remote @import, dark and light blocks, @font-face, radius, pictures and ReCord's --rl-* options. Common region selectors are matched to native roles.

02

DETECT

Every custom property becomes a control: colours get a swatch and a field, opacities a slider, on/off a switch, fonts and pictures fields, and known choices buttons. Large themes filter and open by group.

03

KEEP

Changed values are kept per theme in layout.json. The theme is re-read with those values, so the palette and effect levels change live.

04

NATIVE

Region rules for sidebar, chat, members, messages and composer reach the native window with text, surfaces and radius. A root/body animation becomes a native ground wash; layouts, pseudo-elements and element-level animations still stay out.
